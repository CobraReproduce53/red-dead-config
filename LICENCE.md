## 🧩 About

**Red Dead Redemption 2 Config** is a comprehensive configuration suite for RDR2 on PC featuring graphics presets, overlay menu, gameplay scripts, save manager, performance tweaks, and keybinding profiles.

Based on popular tools like **RDR2 Mod Manager**, **Lenny's Mod Loader**, and **Rampage Trainer**.

---

## ✨ Features

### 🎮 Gameplay Config
- Graphics Presets — low, medium, high, ultra profiles in one click
- Performance Tweaks — optimize shadows, water, and draw distance
- Save Manager — backup and restore story mode saves
- Keybinding Profiles — custom control layouts per activity
- Overlay Menu — quick access to settings in-game

### 🎨 Visual Tweaks
- Color and Contrast Presets — cinematic or realistic looks
- Resolution Scaling — sharpening and upscaler options
- HUD Customization — toggle minimap, ammo, and compass elements

### 🏋️ Scripts & Automation
- Gameplay Scripts — auto-loot, fast travel helpers, and camp utilities
- Photo Mode Presets — saved camera and filter setups
- Session Logger — track playtime and completed activities
- Config Backup — automatic snapshots before each change
